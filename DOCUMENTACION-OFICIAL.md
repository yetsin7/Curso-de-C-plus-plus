# Documentacion oficial de C++

Este archivo reune la referencia mas util para estudiar C++ con buena base
tecnica y avanzar desde fundamentos hasta C++ moderno.

## Referencias principales

- [cppreference - C++](https://en.cppreference.com/w/cpp)
- [ISO C++ Foundation - getting started](https://isocpp.org/get-started)
- [Documentacion de GCC para C++](https://gcc.gnu.org/onlinedocs/)

## Recursos clave para estudiar

- [Tipos y variables](https://en.cppreference.com/w/cpp/language/types)
- [Funciones](https://en.cppreference.com/w/cpp/language/functions)
- [Clases y objetos](https://en.cppreference.com/w/cpp/language/classes)
- [Punteros inteligentes](https://en.cppreference.com/w/cpp/memory)
- [STL y contenedores](https://en.cppreference.com/w/cpp/container)
- [Excepciones](https://en.cppreference.com/w/cpp/language/exceptions)

## Orden recomendado

1. Refuerza sintaxis, tipos y control de flujo.
2. Estudia funciones, referencias y memoria.
3. Pasa a clases, objetos y RAII.
4. Aprende STL, algoritmos y C++ moderno.
